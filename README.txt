HAYDEN IRELAND AUTO WASH — WEBSITE FILES

Included:
- index.html (website markup)
- styles.css (responsive design and styling)
- script.js (mobile menu and booking email form)

HOW TO PREVIEW:
1. Extract the ZIP.
2. Open index.html in your browser (double-click it).

HOW TO PUBLISH FREE WITH GITHUB PAGES:
1. Create a new GitHub repository.
2. Upload all three website files (index.html, styles.css, script.js) to the repository root.
3. Go to repository Settings > Pages.
4. Set deployment source to Deploy from a branch, choose main and /(root), and save.
5. GitHub will show your public website URL after it finishes deploying.
